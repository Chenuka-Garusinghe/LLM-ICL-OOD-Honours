Linear probe explorer

A probe asks a simple question of one layer of Qwen2.5-7B-Instruct: can a straight-line classifier read this label from the hidden state? It is trained on some tasks and tested on others, so a high score means the information is written in the layer in a form that carries over between tasks. Everything below runs on Qwen's real hidden states from the thesis (random demonstrations, 24 evaluation tasks, 60 queries each).

How this page differs from the thesis: each layer's 3,584 numbers are compressed to their top 32 principal components (computed once over all 1,440 queries of a naming, without using any labels), and stored at 8-bit precision. With 32 components the probe lands close to the thesis curves. Everything else follows the thesis: logistic regression with an L2 penalty set by C, four folds by task (train on 18 tasks, test on 6), and AUROC computed within each task and averaged. Data: probe_data.js, built by build_probe_explorer.py.
